# Kazaly Arm Club

A responsive website for a student arm wrestling club.

## Team Members

- Aibek Baimakhan
- Magzhan Assankhan

## Technologies

- HTML
- CSS (Flexbox and Grid)
- JavaScript
- localStorage
- Open-Meteo API

## Pages

- Home
- About Us
- Training
- Gallery
- Contact
- Sign Up
- Log In
- Profile

## Features

- Responsive layout for desktop, tablet and mobile
- Light and dark modes
- Registration, login and member profile
- JavaScript form validation
- Training search and filtering
- Saved training sessions
- Interactive photo gallery
- FAQ search
- Current weather in Kazaly

Registration, contact messages and subscriptions are simulated using browser storage. No data is sent to a server.

## Run Locally

Open the project in VS Code and launch `index.html` using Live Server.

## API

Weather data: [Open-Meteo](https://open-meteo.com/)
